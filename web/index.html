Run

Query syntax. Conditions are field op value, combined with and, or, not and parentheses. A bare word searches paths.

Operators: = != < <= > >= ~ (regex) has (substring or list item) exists missing changed. Fields: path kind (file, service, driver, firewall, com, registry, user, group, certificate, port, wifi) severity change rule and any object field such as signature.status, pe.aslr, start, account, local_ports, server, values.Debugger. Strings take no escapes, so write Windows paths as-is. Click a facet, card or object field to add it.

Examples (click one):

severity >= warning signature.status = unsigned and format = pe rule = "Executable writable by non-admins" writable_by has Users path ~ "\\Program Files( \(x86\))?\\Google\\" and change = created not pe.aslr or not pe.dep signature.signer changed kind = service and start = auto and account ~ "localsystem" kind = firewall and direction = in and action = allow and local_ports missing kind = com and (elevation or shadows_machine) kind = registry and path ~ "\\Run$" unquoted_path or binary_writable_by exists or key_writable_by exists kind = group and privileged and member_sids changed kind = certificate and store = Root and not self_signed kind = port and scope = any and process_signature.status != valid modified_by ~ "^msiexec" and severity >= warning

modified_by needs a Procmon capture: asa procmon import capture.csv.
